# ADR 0014 — Sem a etapa "aguardando peça"

- **Status:** Aceito por padrão — recomendação do backlog (DP-14), 2026-11
- **Tarefas:** —

## Contexto

A RN08 cita "aguardando peça", que não existe no enum `STATUS_ATTENDANCE` nem no
indicador de 5 etapas do frontend.

## Decisão

- Não acrescentar o status; a redação da RN08 deve ser ajustada.

## Consequências

- A oficina usa as observações técnicas para registrar a espera.
